# SuDS Enviro work packs

Two design-forward PDFs to sit beside the brand pack. Edition 1, October 2026. For SuDS Enviro.

| File | What it is |
|---|---|
| `redrawn.pdf` | **Redrawn.** The data sheets, then and now: the 2021 to 2023 originals as supplied, the 2025 first pass, the 2026 web sheets, and the configurator's generated sheet. 13 pages, 1600 x 1000. |
| `beneath-the-site.pdf` | **Beneath the site.** The rebuilt website and its visual direction: site map in section, home, Water Journey, Site Explorer, range and product pages, configurator, design system, next steps and status. 12 pages. |
| `*.html` | The same books as HTML (images referenced from `src/img`). |
| `pages/<book>/page-NN.jpg` | A JPG of every page, for review. |
| `src/` | Sources and scripts, so both can be rebuilt. |

## Sources

- `src/drive/`: Drive originals and the 2025 sheets, decoded to PDF with 2400 px renders. Dates come from each file's PDF metadata.
- `src/sheets/`: the 14 web data sheets in `public/brochures`, printed to PDF exactly as the site prints them (`scripts/sheets.cjs`, static server on :3300).
- `src/gen/`: spec sheets generated by the configurator (`scripts/gen.cjs`).
- `src/shots/`: site captures from `next dev` on :3100. `capture.cjs` (full pages), `frames.cjs` (scroll-driven 3D pages), `journey.cjs` (each Water Journey stop), `phone.cjs` (390 px), `cfg.cjs` (configurator walk-through).

## Rebuild

```
cd work-pack/src/build
python3 redrawn.py && node render.cjs redrawn
python3 site.py && node render.cjs beneath-the-site
```

Needs `pymupdf` and `pillow`, and Playwright with Chromium. `src/img/` is a generated image cache and is not committed.

## Notes

- Old sheets are shown untouched. Redlines mark what a reader would notice (typos, bitmaps, duplicated headings), not the engineering.
- Redrawn page 12 lists figures that differ between editions (SEHDS1800 and SEHDS1200). They are SuDS Enviro's to confirm before anything is printed.
- The hero photograph on Beneath the site page 10 is a direction image from the brand pack, not a finished photograph.
